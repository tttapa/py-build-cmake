# Example project using py-build-cmake, pybind11 and Conan using shared libraries

This is an example package with a C++ extension module using
[pybind11](https://github.com/pybind/pybind11). Dependencies are installed using
the [Conan](https://github.com/conan-io/conan) package manager.

For more information about the file structure and the configuration files,
please see the [`minimal` example](../minimal).
